# IDI_nSight

**IDI_nSight** is an interactive web-based dashboard designed to help users engage meaningfully with their experiments. It provides insights into experimental setups, highlighting what worked, what didn't, and the extent of the outcomes.

## 🌐 Live Demo

Experience the application live at: [IDI_nSight Dashboard](https://i-d-i-nsight.netlify.app/)

## 🧠 Motivation

In experimental research, understanding the nuances of what contributes to success or failure is crucial. IDI_nSight aims to bridge the gap between raw experimental data and actionable insights, enabling users to:

- Comprehend the experimental setup comprehensively.
- Identify successful and unsuccessful components.
- Quantify the impact of different variables. ## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or later)
- npm or yarn ([GitHub - hsmanu1205/object-change-detector-yolo](https://github.com/hsmanu1205/object-change-detector-yolo?utm_source=chatgpt.com))

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/hsmanu1205/IDI_nSight.git
   cd IDI_nSight
   ```


2. Install dependencies: ([Issues · hsmanu1205/Portfolio - GitHub](https://github.com/hsmanu1205/Portfolio/issues?utm_source=chatgpt.com))
   ```bash
   npm install
   # or
   yarn install
   ```


3. Start the development server:
   ```bash
   npm run dev
   # or
   yarn dev
   ```


4. Open [http://localhost:5173](http://localhost:5173) in your browser to view the application.
